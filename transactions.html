🔍 Search Help

Type plain text to search across all fields, or use advanced operators for precise filtering. All terms use AND logic.

Basic Search

coffeeFind transactions matching "coffee" in any field
"whole foods"Exact phrase match
-amazonExclude transactions containing "amazon"

Field Operators

merchant:starbucksSearch merchant name
desc:"direct deposit"Search description
category:foodSearch category (also: cat:)
memo:reimbursementSearch memo notes
bank:chaseSearch bank/account name (also: account:)

Amount & Date Filters

amount:>100Amounts greater than $100
amount:50..200Amounts between $50 and $200
date:2026-03All transactions in March 2026
date:2026-01-01..2026-03-01Date range

Status Flags

is:pendingPending transactions
is:transferTransfers
is:splitSplit transactions
is:manualManual transactions
is:billBill-linked transactions
is:hiddenHidden transactions
is:overrideCategory overrides

Combining Queries

merchant:target amount:>50Target purchases over $50
cat:food -merchant:starbucksFood except Starbucks

Tip: Press Ctrl+F (⌘F on Mac) to quickly focus the search bar.
