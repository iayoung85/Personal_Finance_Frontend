Advanced Mode: CSV Category Management

For advanced users: Download, edit, and upload your entire category configuration as CSV

CSV Format Guide (3 Columns)

Header: action,source_category,target_category

MAPPING: Plaid category to user label
Example: MAPPING,BANK_FEES_ATM_FEES,Bank Fees: Atm Fees

SET_CUSTOM: Custom category (leave source_category empty)
Example: SET_CUSTOM,,Pet Expenses: Dog Food

EXISTING_RULES_RETARGET: Migrate rules to new category
Example: EXISTING_RULES_RETARGET,Old: Category,New: Category

EXISTING_OVERRIDES_RETARGET: Migrate overrides to new category
Example: EXISTING_OVERRIDES_RETARGET,Old: Category,New: Category

Important: All target values must follow format Primary: Detailed
Migration: When changing categories, you MUST retarget existing rules/overrides!
